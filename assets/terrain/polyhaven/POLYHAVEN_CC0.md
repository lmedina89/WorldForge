# Poly Haven terrain materials

These source textures are CC0 assets from Poly Haven and were supplied by the project owner.

Runtime set:
- Grass Ground — primary temperate grass / worn turf
- Brown Mud Leaves 01 — exposed organic soil
- Rocks Ground 02 — rocky ground / exposed stone
- Dry River Pebbles — riverbank / gravel transition
- Rocky Terrain 02 — large-scale rocky macro breakup

Only the 1K diffuse/color, OpenGL normal and ARM maps required by the runtime candidate are bundled. Displacement source maps remain outside the runtime build for now.
