# Game Terrain Workbench 0.4 — PBR V4

PBR V4 keeps the ForgeRTS v0.6.6.8 heightfield, roads and water and replaces only the candidate terrain presentation.

The candidate uses an RGBA splat map (grass / dirt / rock / riverbank), macro-color map, real-scale Poly Haven PBR textures, ARM roughness/AO, OpenGL normal maps and triplanar rocky ground.

Use CURRENT GAME vs PBR V4 with the same map/seed. Primary acceptance views: WIDE for material distribution, CLOSE for repetition/blend quality, GROUND for normal/roughness scale, TOP for road and bank masks.
